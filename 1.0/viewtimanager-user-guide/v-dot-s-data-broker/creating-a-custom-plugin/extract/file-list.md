<h1><strong><span align="center">File List Connector</span></strong></h1><p></p><p>The <strong>File List Connector</strong> is a scheduled connector designed to read files from a specific directory on the Viewtilog server and move them to another location for further processing. This connector is especially useful when working with external systems that drop files (e.g., CSV logs, reports, or call detail records).</p><p>Once the files are moved to the designated output directory, they can later be sent to an external device in the <strong>Load stage</strong> using the <strong>SCP Producer</strong> (explained in detail in a later section).</p><p>Unlike continuous connectors such as the <strong>Ethernet Streamer</strong>, the File List Connector operates on a <strong>scheduled execution model</strong>: it runs at defined intervals or according to a cron expression, depending on the selected <strong>Frequency Type</strong>.</p><p></p><h2><strong>Key Features</strong></h2><ul><li><p>Reads files from a configurable <em>to-collect</em> directory.</p></li><li><p>Moves files to a <em>to-send</em> directory for further processing.</p></li><li><p>Supports <strong>Periodic execution</strong> (every X seconds) or <strong>Scheduled execution</strong> (cron expression).</p></li><li><p>Allows setting the <strong>maximum number of files</strong> to process per execution.</p></li><li><p>File suffix can be specified (e.g., <code>.csv</code>).</p></li><li><p>Works seamlessly with <strong>SCP Producer</strong> to deliver files to remote destinations.</p></li></ul><p></p><h2><strong>Step-by-Step Configuration</strong></h2><p>Follow these steps to configure the <strong>File List Connector</strong>:</p><ol><li><p><strong>Select the Connector Type</strong></p><ul><li><p>In the <em>Editing Extract Stage</em> window, choose <strong>File List Connector</strong> from the dropdown list.</p></li></ul></li><li><p><strong>Assign a Pipeline Name</strong></p><ul><li><p>Enter a <strong>unique pipeline name</strong>.</p></li><li><p>Example: <code>my_file_list_connector</code>.</p></li></ul></li><li><p><strong>Configure Execution Timing</strong></p><ul><li><p>Choose <strong>Frequency Type</strong>:</p><ul><li><p><strong>Periodic</strong> → Executes every X seconds (configured in <em>Refresh Time</em>).</p></li><li><p><strong>Scheduled</strong> → Executes according to a cron expression.</p></li></ul></li><li><p>Example: Periodic with refresh time = <code>60</code> seconds.</p></li></ul></li><li><p><strong>Define Paths</strong></p><ul><li><p><strong>To-collect path</strong>: The directory where files are initially stored.</p></li><li><p><strong>To-send path</strong>: The directory where the files will be moved after being collected.</p></li></ul></li><li><p><strong>Set File Properties</strong></p><ul><li><p><strong>Suffix</strong>: Defines the expected file format (e.g., <code>.csv</code>).</p></li><li><p><strong>Max Files</strong>: Maximum number of files to process during one execution.</p></li></ul></li><li><p><strong>Confirm Configuration</strong></p><ul><li><p>Once all parameters are set, click <strong>Confirm</strong> to save and activate the connector.</p><p></p></li></ul></li></ol><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/JQKTY4r9i7A0faASpOYL.png" align="center"></figure><p></p><h3><strong>Example Configuration (based on image)</strong></h3><ul><li><p><strong>Connector Type</strong>: File List Connector</p></li><li><p><strong>Pipeline Name</strong>: <code>my_file_list_connector</code></p></li><li><p><strong>Frequency Type</strong>: Periodic</p></li><li><p><strong>Refresh Time</strong>: 60 seconds</p></li><li><p><strong>Number of Executions</strong>: <code>-1</code> (runs indefinitely)</p></li><li><p><strong>To-collect Path</strong>: <code>/opt/vn/dhyana/var/data/%%%PLUGIN_NAME%%%/to_collect/</code></p></li><li><p><strong>To-send Path</strong>: <code>/opt/vn/dhyana/var/data/%%%PLUGIN_NAME%%%/to_send/</code></p></li><li><p><strong>Suffix</strong>: <code>.csv</code></p></li><li><p><strong>Max Files</strong>: 50</p><p></p></li></ul><h2><strong>Summary</strong></h2><p>The File List Connector is ideal for scenarios where external systems drop files into a shared location for collection. By moving files between directories, it ensures orderly processing and prepares the data for secure delivery using Producers like <strong>SCP</strong>.</p>
