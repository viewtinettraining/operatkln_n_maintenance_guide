<h1><strong><span align="center">Command Executor Connector</span></strong></h1><p></p><p><span align="justify">The Command Executor Connector allows the execution of custom commands or scripts directly from the Visual Smart Data Broker (VSDB). This connector is highly flexible, as it can be used to gather data from virtually any command-line tool or script available on the host system. The results of these executions are then parsed and processed in a similar way to CSV-based connectors.</span></p><p></p><h2><strong>Configuration Parameters</strong></h2><ul><li><p><strong>Frequency Type</strong><br>Same behavior as in SNMP, ICMP, and CSV connectors:</p><ul><li><p><strong>Periodic</strong>: Executes the pipeline at fixed intervals defined by <em>Refresh Time (secs)</em>.</p></li><li><p><strong>Scheduled</strong>: Uses a cron expression to define precise execution times.</p></li></ul></li><li><p><strong>Number of Executions</strong></p><ul><li><p><code>-1</code>: The connector will run indefinitely.</p></li><li><p>Positive integer: The connector will stop after completing the specified number of runs.</p></li></ul></li><li><p><strong>Command</strong><br>The command or script to be executed.<br>By clicking the <strong>pencil icon</strong>, an editor opens where you can define the command or write a <strong>bash script</strong>. The script must be designed to return structured data that will be parsed by the connector.</p><p></p></li></ul><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/9EMixQCW5Gj6d2Otmiuj.png" align="center"></figure><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/PvBqL9VlOPjGwJ13bMfX.png"></figure><p></p><h2><strong>How It Works</strong></h2><ol><li><p>The defined command or script is executed according to the selected frequency type.</p></li><li><p>The command output is captured by the connector.</p></li><li><p>The resulting data is parsed in the same way as CSV connectors:</p><ul><li><p>Fields must be defined manually, or</p></li><li><p>Imported from a sample file using headers, ensuring the output structure matches the expected schema.</p></li></ul></li></ol><p>This makes the Command Executor Connector extremely versatile, as it allows integrating data from scripts that query databases, call APIs, interact with system commands, or generate custom reports.</p><p></p><h2><strong>Typical Use Cases</strong></h2><ul><li><p>Executing <strong>bash scripts</strong> to gather OS metrics not directly available via SNMP.</p></li><li><p>Running <strong>database queries</strong> that output results in a CSV-like format.</p></li><li><p>Interfacing with external APIs via CLI tools (e.g., <code>curl</code>) and capturing the response.</p></li><li><p>Collecting <strong>custom application logs or counters</strong> exposed through scripts.</p></li></ul><p></p><h2><strong>Summary</strong></h2><p>The Command Executor Connector enables VSDB to integrate with <strong>any data source accessible through the command line</strong>. With support for both scheduled and periodic execution, it offers unmatched flexibility for custom integrations. Its similarity to the CSV Connector in terms of field definition ensures that the data obtained is immediately ready to flow through the transformation and loading stages of the ETL pipeline.</p>
