<h1><strong><span align="center">Conector Command Executor</span></strong></h1><p></p><p><span align="justify">O Conector Command Executor permite a execução de comandos personalizados ou scripts diretamente do Visual Smart Data Broker (VSDB). Este conector é altamente flexível, pois pode ser usado para coletar dados de praticamente qualquer ferramenta de linha de comando ou script disponível no sistema host. Os resultados dessas execuções são então analisados e processados de forma semelhante aos conectores baseados em CSV.</span></p><p></p><h2><strong>Parâmetros de Configuração</strong></h2><ul><li><p><strong>Tipo de Frequência</strong><br>Mesmo comportamento que nos conectores SNMP, ICMP e CSV:</p><ul><li><p><strong>Periódico</strong>: Executa o pipeline em intervalos fixos definidos por <em>Tempo de Atualização (segs)</em>.</p></li><li><p><strong>Agendado</strong>: Usa uma expressão cron para definir tempos de execução precisos.</p></li></ul></li><li><p><strong>Número de Execuções</strong></p><ul><li><p><code>-1</code>: O conector será executado indefinidamente.</p></li><li><p>Inteiro positivo: O conector irá parar após concluir o número especificado de execuções.</p></li></ul></li><li><p><strong>Comando</strong><br>O comando ou script a ser executado.<br>Ao clicar no <strong>ícone de lápis</strong>, um editor é aberto onde você pode definir o comando ou escrever um <strong>script bash</strong>. O script deve ser projetado para retornar dados estruturados que serão analisados pelo conector.</p><p></p></li></ul><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/9EMixQCW5Gj6d2Otmiuj.png" align="center"></figure><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/PvBqL9VlOPjGwJ13bMfX.png"></figure><p></p><h2><strong>Como Funciona</strong></h2><ol><li><p>O comando ou script definido é executado de acordo com o tipo de frequência selecionado.</p></li><li><p>A saída do comando é capturada pelo conector.</p></li><li><p>Os dados resultantes são analisados da mesma forma que os conectores CSV:</p><ul><li><p>Os campos devem ser definidos manualmente, ou</p></li><li><p>Importados de um arquivo de exemplo usando cabeçalhos, garantindo que a estrutura de saída corresponda ao esquema esperado.</p></li></ul></li></ol><p>Isso torna o Conector Command Executor extremamente versátil, pois permite a integração de dados de scripts que consultam bancos de dados, chamam APIs, interagem com comandos do sistema ou geram relatórios personalizados.</p><p></p><h2><strong>Casos de Uso Típicos</strong></h2><ul><li><p>Execução de <strong>scripts bash</strong> para coletar métricas do SO não disponíveis diretamente via SNMP.</p></li><li><p>Execução de <strong>consultas a banco de dados</strong> que geram resultados em formato semelhante a CSV.</p></li><li><p>Integração com APIs externas via ferramentas de CLI (ex.: <code>curl</code>) e captura da resposta.</p></li><li><p>Coleta de <strong>logs ou contadores de aplicativos personalizados</strong> expostos por meio de scripts.</p></li></ul><p></p><h2><strong>Resumo</strong></h2><p>O Conector Command Executor permite que o VSDB se integre a <strong>qualquer fonte de dados acessível pela linha de comando</strong>. Com suporte a execuções agendadas e periódicas, oferece flexibilidade inigualável para integrações personalizadas. Sua semelhança com o Conector CSV em termos de definição de campos garante que os dados obtidos estejam prontos imediatamente para fluir pelas etapas de transformação e carregamento do pipeline ETL.</p>
