<h1><strong><span align="center">Pré-requisitos para o Conector WinRM</span></strong></h1><p></p><p>Antes de configurar o <strong>Conector de Gerenciamento Remoto do Windows (WinRM)</strong>, certos pré-requisitos devem ser atendidos nos servidores Windows de destino. Essas etapas garantem uma comunicação remota segura e confiável entre o servidor e o Viewtilog.</p><hr><h2><strong>1. Habilite e Configure o WinRM</strong></h2><ul><li><p>Abra o <strong>PowerShell como Administrador</strong>.</p></li><li><p>Execute o comando de configuração rápida:</p><pre><code class="language-powershell">winrm quickconfig
</code></pre></li></ul><p>Habilite a autenticação básica:</p><pre><code class="language-powershell">winrm set winrm/config/service/Auth '@{Basic="true"}'</code></pre><p>Aumente o tamanho máximo da mensagem e as operações simultâneas:</p><pre><code class="language-powershell">winrm set winrm/config '@{MaxEnvelopeSizekb="1024"}'
winrm set winrm/config/service '@{MaxConcurrentOperationsPerUser="1500"}'</code></pre><p></p><h2><strong>2. Crie um Usuário para o WinRM</strong></h2><ul><li><p>Crie um usuário dedicado (se necessário):</p><pre><code class="language-powershell">New-LocalUser "WinRMUser" -Password (ConvertTo-SecureString "Password123!" -AsPlainText -Force)
</code></pre></li><li><p>Adicione o usuário ao grupo de <strong>Usuários de Gerenciamento Remoto</strong> (Remote Management Users):</p><pre><code class="language-powershell">Add-LocalGroupMember -Group "Remote Management Users" -Member "WinRMUser"
</code></pre></li></ul><h2><strong>3. Configure a Autenticação Segura (HTTPS)</strong></h2><ol><li><p>Gere ou instale um <strong>Certificado de Autenticação de Servidor</strong>.<br>Exemplo de certificado auto-assinado:</p><pre><code class="language-powershell">$hostName = $env:COMPUTERNAME
$hostIP = (Get-NetAdapter | Get-NetIPAddress).IPv4Address | Out-String
$srvCert = New-SelfSignedCertificate -DnsName $hostName, $hostIP -CertStoreLocation Cert:\LocalMachine\My
</code></pre></li><li><p>Vincule o certificado ao WinRM:</p><pre><code class="language-powershell">winrm create winrm/config/Listener?Address=*+Transport=HTTPS '@{Hostname="seu-fqdn-de-servidor"; CertificateThumbprint="THUMBPRINT"}'
</code></pre></li><li><p>Configure o serviço para usar comunicação criptografada:</p><pre><code class="language-powershell">winrm set winrm/config/service '@{AllowUnencrypted="false"; CertificateThumbprint="THUMBPRINT"}'
</code></pre></li></ol><h2><strong>4. Verifique os Grupos Disponíveis para o Usuário WinRM</strong></h2><ul><li><p>Certifique-se de que o usuário WinRM tenha as associações de grupo necessárias:</p><ul><li><p><strong>Usuários de Gerenciamento Remoto</strong> (Remote Management Users) (obrigatório).</p></li><li><p><strong>Usuários de Log de Desempenho</strong> (Performance Log Users) (para consultar contadores de desempenho).</p></li><li><p><strong>Leitores de Log de Eventos</strong> (Event Log Readers) (para ler logs de eventos).</p></li></ul></li><li><p>Para verificar os grupos:</p><pre><code class="language-powershell">net user WinRMUser</code></pre></li></ul><h2><strong>5. Habilite Permissões WMI</strong></h2><ul><li><p>Abra o <strong>wmimgmt.msc</strong> (Console de Gerenciamento WMI).</p></li><li><p>Clique com o botão direito em <strong>Controle WMI (Local)</strong> (WMI Control) → <em>Propriedades</em>.</p></li><li><p>Vá para a guia <strong>Segurança</strong> → expanda <em>Root</em> → selecione <strong>CIMV2</strong>.</p></li><li><p>Clique em <strong>Segurança</strong> → Adicione o <strong>usuário WinRM</strong>.</p></li><li><p>Conceda permissões de <strong>Habilitar Remotamente</strong> (Remote Enable) e <strong>Executar Métodos</strong> (Execute Methods).</p></li></ul><p></p><h2><strong>6. Configure o Acesso DCOM</strong></h2><ul><li><p>Abra <strong>dcomcnfg</strong> (Serviços de Componentes).</p></li><li><p>Navegue para: <em>Serviços de Componentes → Computadores → Meu Computador</em>.</p></li><li><p>Clique com o botão direito → <strong>Propriedades</strong> → <em>Segurança COM</em> (COM Security).</p></li><li><p>Em <strong>Permissões de Inicialização e Ativação</strong>, clique em <strong>Editar Limites</strong>.</p></li><li><p>Adicione o <strong>usuário WinRM</strong> e conceda:</p><ul><li><p><strong>Execução Remota</strong> (Remote Execution)</p></li><li><p><strong>Ativação Remota</strong> (Remote Activation)</p></li></ul></li></ul><p></p><h2><strong>7. Habilite a Auditoria de Logon de Evento</strong></h2><p>Para capturar eventos de login de usuário (ex., Event IDs 4624, 4625), habilite a auditoria de logon:</p><ol><li><p>Abra a <strong>Política de Segurança Local</strong> (<code>secpol.msc</code>).</p></li><li><p>Navegue para: <em>Políticas Locais → Política de Auditoria</em>.</p></li><li><p>Habilite:</p><ul><li><p><strong>Auditoria de eventos de logon (Sucesso, Falha)</strong></p></li><li><p><strong>Auditoria de eventos de logon de conta (Sucesso, Falha)</strong></p></li></ul></li></ol><p></p><h2><strong>8. Regras de Firewall</strong></h2><p>Habilite o tráfego de entrada na porta HTTPS padrão do WinRM (5986):</p><pre><code class="language-powershell">netsh advfirewall firewall add rule name="WinRM HTTPS" protocol=TCP dir=in localport=5986 action=allow</code></pre><hr><p></p><h2><strong>9. Exportação e Conversão de Certificado</strong></h2><ul><li><p>Exporte o certificado para <strong>.cer</strong>:</p><pre><code class="language-powershell">Export-Certificate -Cert $srvCert -FilePath "C:\Temp\winrm_server.cer"</code></pre></li><li><p>Copie o arquivo <code>.cer</code> para o servidor onde o <strong>Viewtilog</strong> é executado. Isso garante confiança na conexão segura.</p></li><li><p>Se o Viewtilog exigir um formato <strong>.pem</strong>, converta o arquivo <code>.cer</code> usando o OpenSSL:</p><pre><code class="language-powershell">openssl x509 -inform DER -in winrm_server.cer -out winrm_server.pem
</code></pre></li></ul><hr><p></p><h3>⚠️ Aviso</h3><ul><li><p>O <strong>idioma do sistema operacional</strong> deve ser levado em consideração. Os nomes dos grupos (ex., <em>Usuários de Gerenciamento Remoto</em>, <em>Leitores de Log de Eventos</em>) podem diferir dependendo se o Windows estiver em inglês, espanhol, português ou outro idioma. Ajuste adequadamente.</p></li><li><p>Excluir ou substituir o certificado pode interromper a conexão. Mantenha sempre um backup dos arquivos <code>.cer</code> e <code>.pem</code>.</p></li></ul><p></p>
