<h1><strong><span align="center">Conector MongoDB</span></strong></h1><p></p><p>O <strong>Conector MongoDB</strong> permite que os pipelines extraiam dados diretamente de uma coleção do MongoDB. Este conector é útil quando você precisa integrar documentos JSON estruturados de aplicativos externos, como alarmes, logs ou metadados, no pipeline ETL do Viewtinet.</p><p>Ao contrário de ouvintes (listeners) como o Ethernet Streamer, o Conector MongoDB é um <strong>conector agendado</strong>. Ele é executado periodicamente ou de acordo com uma configuração cron, recuperando novos documentos da coleção especificada.</p><p></p><h2><strong>Principais Recursos</strong></h2><ul><li><p>Conecta-se a uma instância do MongoDB usando uma <strong>URI do MongoDB</strong> padrão.</p></li><li><p>Suporta execução agendada: <strong>Periódico</strong> (a cada X segundos) ou <strong>Agendado</strong> (expressão cron).</p></li><li><p>Copia documentos de um <strong>banco de dados</strong> e de uma <strong>coleção</strong> específicos.</p></li><li><p>Usa uma <strong>coluna de filtro de tempo</strong> para ler apenas os documentos mais recentes.</p></li><li><p>Rastreia a última posição lida com um arquivo <code>.tf</code> para evitar cópias duplicadas.</p></li><li><p>Suporta extração seletiva de <strong>campos</strong>, que são mapeados posteriormente no pipeline.</p></li></ul><p></p><h2><strong>Parâmetros de Configuração</strong></h2><ul><li><p><strong>URI de Conexão</strong>: URI do MongoDB usada para conectar ao servidor. Deve seguir o <a href="https://www.mongodb.com/docs/manual/reference/connection-string/" target="_blank">Formato URI de String de Conexão do MongoDB</a>.<br>Exemplo: <code>mongodb://usuario:senha@127.0.0.1:27017</code></p></li><li><p><strong>Banco de Dados</strong>: O nome do banco de dados dentro do MongoDB.<br>Exemplo: <code>viewtinet</code></p></li><li><p><strong>Coleção</strong>: A coleção da qual extrair os documentos.<br>Exemplo: <code>alarms</code></p></li><li><p><strong>Tamanho do Lote</strong> <em>(opcional)</em>: Número máximo de documentos para copiar a cada vez que o conector for executado.<br>Padrão: <code>1,000,000</code> (1M).<br>⚠ Definir um valor baixo pode fazer com que o plugin fique atrasado se novos dados forem adicionados rapidamente.</p></li><li><p><strong>Coluna de filtro de tempo</strong>: Campo usado para classificar e filtrar documentos. Normalmente é um campo de carimbo de data/hora, como <code>__ttl_created_at</code>.</p></li><li><p><strong>Valor inicial do filtro de tempo</strong>: O valor inicial em milissegundos/nanossegundos para filtrar documentos.</p><ul><li><p><code>0</code> ou vazio → todos os documentos serão copiados.</p></li><li><p>Qualquer outro valor → apenas documentos mais recentes que esse carimbo de data/hora serão processados.</p></li></ul></li><li><p><strong>Caminho do arquivo de filtro de tempo</strong>: Local onde o arquivo <code>.tf</code> é armazenado. Este arquivo salva o último carimbo de data/hora copiado para garantir a continuidade entre as reinicializações.<br>⚠ <strong>Nota</strong>: Se você excluir este arquivo, o conector será reiniciado do zero, recopiando a coleção inteira.</p></li><li><p><strong>Campos</strong>: Lista de chaves de documento do MongoDB a serem copiadas. Cada campo se torna uma coluna na saída. Os campos podem ser definidos manualmente na GUI.</p></li></ul><p></p><h2><strong>Exemplo de Campos</strong></h2><p>Documentos do MongoDB são armazenados no formato JSON. O conector extrai as chaves de nível superior como campos e as converte em strings.</p><p><strong>Documento de exemplo</strong>:</p><pre><code class="language-json">{
  "uuid": "e4c2ebe9-1a35-4ba3-848b-476eb7e7764c",
  "created_at": "2022-10-18T14:37:03.913831Z",
  "owner": {
    "name": "admin",
    "tenant": "Viewtinet"
  }
}
</code></pre><p><strong>Campos extraídos</strong>:</p><ul><li><p><code>uuid</code>: <code>e4c2ebe9-1a35-4ba3-848b-476eb7e7764c</code></p></li><li><p><code>created_at</code>: <code>2022-10-18T14:37:03.913831Z</code></p></li><li><p><code>owner</code>: <code>{"name": "admin", "tenant": "Viewtinet"}</code></p></li></ul><p>Para <strong>elementos JSON aninhados</strong> (ex., <code>owner.name</code>, <code>owner.tenant</code>), você deve usar o <strong>Grid Handler JsonParser</strong> no estágio <strong>Transform</strong> para extrair os subcampos.</p><p></p><h2><strong>Configuração Passo a Passo </strong></h2><ol><li><p><strong>Selecione o Conector MongoDB</strong></p><ul><li><p>Abra a lista <em>Tipo de Conector/Streamer</em> e selecione <strong>Conector MongoDB</strong>.</p></li></ul></li><li><p><strong>Atribua um Nome ao Pipeline</strong></p><ul><li><p>Insira um nome exclusivo, ex. <code>mongodb-alarms</code>.</p></li></ul></li><li><p><strong>Configure a Frequência</strong></p><ul><li><p>Escolha entre <strong>Periódico</strong> (a cada X segundos) ou <strong>Agendado</strong> (cron).</p></li><li><p>Exemplo: Periódico a cada 30 segundos.</p></li></ul></li><li><p><strong>Banco de Dados e Coleção</strong></p><ul><li><p>Defina o <strong>Banco de Dados</strong> (ex., <code>viewtinet</code>) e a <strong>Coleção</strong> (ex., <code>alarms</code>).</p></li></ul></li><li><p><strong>Tamanho do Lote</strong></p><ul><li><p>Defina o número máximo de documentos para recuperar por execução.</p></li><li><p>Exemplo: <code>10000</code>.</p></li></ul></li><li><p><strong>Filtro de Tempo</strong></p><ul><li><p>Especifique um campo para usar como filtro de tempo (ex., <code>__ttl_created_at</code>).</p></li><li><p>Forneça o valor inicial (<code>0</code> para buscar todos os documentos).</p></li><li><p>Defina um caminho para salvar o arquivo de rastreamento <code>.tf</code>.</p></li></ul></li><li><p><strong>Configuração de Conexão</strong></p><ul><li><p>Forneça o <strong>usuário</strong>, a <strong>senha</strong> e o <strong>host</strong> com porta do MongoDB.</p></li><li><p>Exemplo: <code>127.0.0.1:23461</code>.</p></li></ul></li><li><p><strong>Defina os Campos</strong></p><ul><li><p>Adicione os campos a serem extraídos dos documentos.</p></li><li><p>Exemplo: <code>_id</code>, <code>uuid</code>, <code>created_at</code>, <code>owner</code>, <code>permissions</code>, <code>rules</code>.</p></li></ul></li></ol><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/qtnl50OgwqCCnxUGO8FD.png" align="center"></figure><p></p><p></p><h2><strong>Resumo</strong></h2><p>O Conector MongoDB integra coleções do MongoDB no fluxo de trabalho ETL do Viewtinet. Ele fornece extração incremental confiável ao rastrear carimbos de data/hora, suporta mapeamento de campo seletivo e garante ausência de registros duplicados durante reinicializações. Para estruturas JSON aninhadas, é necessária uma transformação adicional com os Grid Handlers.</p><p></p>
