<h1><strong><span align="center">MongoDB Connector</span></strong></h1><p></p><p>The <strong>MongoDB Connector</strong> allows pipelines to extract data directly from a MongoDB collection. This connector is useful when you need to integrate structured JSON documents from external applications, such as alarms, logs, or metadata, into the Viewtinet ETL pipeline.</p><p>Unlike listeners such as the Ethernet Streamer, the MongoDB Connector is a <strong>scheduled connector</strong>. It runs periodically or according to a cron configuration, retrieving new documents from the specified collection.</p><p></p><h2><strong>Key Features</strong></h2><ul><li><p>Connects to a MongoDB instance using a standard <strong>MongoDB URI</strong>.</p></li><li><p>Supports scheduled execution: <strong>Periodic</strong> (every X seconds) or <strong>Scheduled</strong> (cron expression).</p></li><li><p>Copies documents from a specific <strong>database</strong> and <strong>collection</strong>.</p></li><li><p>Uses a <strong>time filter column</strong> to read only the newest documents.</p></li><li><p>Tracks the last read position with a <code>.tf</code> file to prevent duplicate copies.</p></li><li><p>Supports selective extraction of <strong>fields</strong>, which are later mapped in the pipeline.</p></li></ul><p></p><h2><strong>Configuration Parameters</strong></h2><ul><li><p><strong>Connection URI</strong>: MongoDB URI used to connect to the server. Must follow <a href="https://www.mongodb.com/docs/manual/reference/connection-string/" target="_blank">MongoDB's Connection String URI Format</a>.<br>Example: <code>mongodb://username:password@127.0.0.1:27017</code></p></li><li><p><strong>Database</strong>: The database name inside MongoDB.<br>Example: <code>viewtinet</code></p></li><li><p><strong>Collection</strong>: The collection from which to extract documents.<br>Example: <code>alarms</code></p></li><li><p><strong>Batch size</strong> <em>(optional)</em>: Maximum number of documents to copy each time the connector runs.<br>Default: <code>1,000,000</code> (1M).<br>⚠ Setting a low value may cause the plugin to fall behind if new data is added rapidly.</p></li><li><p><strong>Time filter column</strong>: Field used to sort and filter documents. Typically a timestamp field, such as <code>__ttl_created_at</code>.</p></li><li><p><strong>Time filter starting value</strong>: The initial value in milliseconds/nanoseconds for filtering documents.</p><ul><li><p><code>0</code> or empty → all documents will be copied.</p></li><li><p>Any other value → only documents newer than this timestamp will be processed.</p></li></ul></li><li><p><strong>Time filter file path</strong>: Location where the <code>.tf</code> file is stored. This file saves the last copied timestamp to ensure continuity between restarts.<br>⚠ <strong>Note</strong>: If you delete this file, the connector will restart from scratch, re-copying the entire collection.</p></li><li><p><strong>Fields</strong>: List of MongoDB document keys to copy. Each field becomes a column in the output. Fields can be defined manually in the GUI.</p></li></ul><p></p><h2><strong>Fields Example</strong></h2><p>MongoDB documents are stored in JSON format. The connector extracts top-level keys as fields and converts them to strings.</p><p><strong>Sample document</strong>:</p><pre><code class="language-json">{
  "uuid": "e4c2ebe9-1a35-4ba3-848b-476eb7e7764c",
  "created_at": "2022-10-18T14:37:03.913831Z",
  "owner": {
    "name": "admin",
    "tenant": "Viewtinet"
  }
}
</code></pre><p><strong>Extracted fields</strong>:</p><ul><li><p><code>uuid</code>: <code>e4c2ebe9-1a35-4ba3-848b-476eb7e7764c</code></p></li><li><p><code>created_at</code>: <code>2022-10-18T14:37:03.913831Z</code></p></li><li><p><code>owner</code>: <code>{"name": "admin", "tenant": "Viewtinet"}</code></p></li></ul><p>For <strong>nested JSON elements</strong> (e.g., <code>owner.name</code>, <code>owner.tenant</code>), you must use the <strong>JsonParser Grid Handler</strong> in the <strong>Transform</strong> stage to extract sub-fields.</p><p></p><h2><strong>Step-by-Step Configuration </strong></h2><ol><li><p><strong>Select the MongoDB Connector</strong></p><ul><li><p>Open the <em>Connector/Streamer Type</em> list and select <strong>MongoDB Connector</strong>.</p></li></ul></li><li><p><strong>Assign a Pipeline Name</strong></p><ul><li><p>Enter a unique name, e.g. <code>mongodb-alarms</code>.</p></li></ul></li><li><p><strong>Configure Frequency</strong></p><ul><li><p>Choose between <strong>Periodic</strong> (every X seconds) or <strong>Scheduled</strong> (cron).</p></li><li><p>Example: Periodic every 30 seconds.</p></li></ul></li><li><p><strong>Database and Collection</strong></p><ul><li><p>Set the <strong>Database</strong> (e.g., <code>viewtinet</code>) and <strong>Collection</strong> (e.g., <code>alarms</code>).</p></li></ul></li><li><p><strong>Batch Size</strong></p><ul><li><p>Define the maximum number of documents to retrieve per execution.</p></li><li><p>Example: <code>10000</code>.</p></li></ul></li><li><p><strong>Time Filter</strong></p><ul><li><p>Specify a field to use as time filter (e.g., <code>__ttl_created_at</code>).</p></li><li><p>Provide the starting value (<code>0</code> to fetch all documents).</p></li><li><p>Set a path to save the <code>.tf</code> tracking file.</p></li></ul></li><li><p><strong>Connection Config</strong></p><ul><li><p>Provide MongoDB <strong>username</strong>, <strong>password</strong>, and <strong>host</strong> with port.</p></li><li><p>Example: <code>127.0.0.1:23461</code>.</p></li></ul></li><li><p><strong>Define Fields</strong></p><ul><li><p>Add fields to extract from the documents.</p></li><li><p>Example: <code>_id</code>, <code>uuid</code>, <code>created_at</code>, <code>owner</code>, <code>permissions</code>, <code>rules</code>.</p></li></ul></li></ol><p></p><figure align="center"><img MongoDB Connector integrates MongoDB collections into the Viewtinet ETL workflow. It provides reliable incremental extraction by tracking timestamps, supports selective field mapping, and ensures no duplicate records during restarts. For nested JSON structures, additional transformation with Grid Handlers is required.</p><p></p>
