# **<span align="center">IP Address to Country Code</span>**

<br />

The **IP Address to Country Code** grid handler provides a fast and efficient way to perform geolocation on network data. 

**Definition:** *This handler is able to add/update a string, ipaddress or ipaddressv6 column by geolocating IP addresses to country codes.*

By taking a source IP address from the data stream, this handler compares it against a predefined database and assigns the corresponding 2-letter Country Code to a destination column.

<br />

---

## **Prerequisites: The Mapping File**

Before configuring the grid handler, the system requires a structured CSV mapping file that correlates IP subnet ranges to their respective country codes. 

To obtain and maintain this mapping file automatically, you must create a pipeline using the **"IP to Country Code" connector**. This connector periodically downloads and updates the geolocation database. 

<div class="sd-callout" data-callout-type="info"><strong>Reference:</strong> Please refer to the <strong>Extract</strong> section of this documentation to see exactly how to configure the "IP to Country Code" connector.</div>

## **Configuration**

Once the mapping file is available on the server, you can configure the Grid Handler.

<br />

<figure align="center"><img src="https://viewtinettraining.github.io/viewtinettraining635.github.io/images/ip-to-country-config.png" align="center"></figure>

<br />

The configuration requires three key parameters:

-   **Column:** The source column in your grid that contains the IP address you want to geolocate. In the example above, this is set to `remip`.
-   **Target Column:** The destination column where the handler will write the resulting 2-letter country code. If the column doesn't exist, it will be created. In the example, it writes to `remcountry`.
-   **Mapping File Path:** The absolute path on the server where the geolocation CSV file is stored (e.g., `/opt/vn/dhyana/var/data/ip2country/ip2countrysys`). This file is generated by the Extract connector mentioned in the prerequisites.
