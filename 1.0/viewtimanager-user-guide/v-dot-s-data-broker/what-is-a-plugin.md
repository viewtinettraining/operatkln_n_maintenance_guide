<h1><strong><span align="center">What is a Plugin?</span></strong></h1><p><span align="justify">A plugin is a concept introduced by Viewtinet to integrate the data sources in an easy way using the GUI. A plugin contains the ETL stages to get the information from the data sources using different protocols ( SNMP, ICMP, Netflow, SNMP, CSV, XDR). It covers the data transformation and loading into the database. After this is done, you can use tools like Metrics Composer (See Viewtisight User Guide) to create metrics from the loaded data.</span></p><p></p><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/p5zE6ydAjaAmMLFipxVp.png" align="middle"></figure><p>A plugin consists of:</p><ul><li><p><strong>Pipeline:</strong> the set of stages that allow to get the data, transform it, and load it in a time-series database. Below is an explanation for each stage:</p><ul><li><p><strong>Extract:</strong> Stage used to connect with a data source and extract its data. In this stage, there are defined the fields to be gotten according to the protocol used. For example, SNMP OIDs, fields from Syslog, NetFlow, or csv file, and the IP for those data sources.</p></li><li><p><strong>Transform:</strong> The data obtained in the previous stage can be transformed using mathematical operations ( for numerical fields) in new fields. It is also possible to transform the data by adding information using the CSV decorator feature. Other possibilities are Column Remover, Column Constant Adder, Date Converter, Regex, and Key-Value, among others.</p></li><li><p><strong>Load:</strong> the data obtained and transformed can be dumped on a CSV file or loaded to time series databases. It can even perform both actions at the same time. also are defined the table, fields name, and their type ( Varchar, Numeric, BIGINT)</p></li><li><p><strong>Schema:</strong> at this stage, the data is prepared to be used on Viewtisight Module. This is where the metrics and dimensions are defined.</p></li><li><p><strong>Dashboards:</strong> this stage is optional. A plugin can have predefined dashboards for specific data sources.</p></li></ul></li><li><p><strong>Name:</strong> Descriptive name of plugin e.g. "Fortinet's Network Monitoring Template".</p></li><li><p><strong>Category:</strong> Each plugin belongs to a category, e.g SNMP, Networking, SSH, Syslog, among others.</p></li><li><p><strong>Dependencies:</strong> it shows the modules that are mandatory to install the plugin.</p></li><li><p><strong>Description:</strong> A description of the plugin e.g: "Viewtinet Template for Fortinet Firewalls: status, health and interface monitoring ( includes dashboards )".</p></li><li><p><strong>Image:</strong> An image in jpg/png format to identify the plugin.</p></li></ul><p></p><p>The following screenshots show all the plugin fields:</p><p></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/nKjjFtOOWRrWf1YMpjgy.png" align="middle"></figure><p></p>
