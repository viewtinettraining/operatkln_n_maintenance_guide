# **<span align="center">Plugin Categories</span>**

<br />

Each plugin belongs to one category.

<br />

<figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/4VZFQhoxLAIiq6fD3wuq.png"></figure>

<br />

The available categories are the following:

-   CDR
-   ICMP
-   My Category
-   Network
-   Optimization
-   SNMP
-   SSH
-   Sflow
-   Syslog
-   Viewtinet
-   WMI

When you click on one category, it will filter the available plugin accordingly.
