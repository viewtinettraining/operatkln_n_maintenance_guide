<h1><strong><span align="center">O que é um Template de Plugin?</span></strong></h1><p></p><p><span align="justify">Um template de plugin fornece configurações predefinidas que simplificam a integração de fontes de dados. A Viewtinet distribui uma biblioteca abrangente de templates de plugins cobrindo diferentes fabricantes e protocolos, incluindo ICMP, SNMP e muitos outros.</span></p><p><span align="justify">Cada template vem com as etapas de ETL (Extrair, Transformar, Carregar) e Dashboards já configurados, permitindo que você integre novas fontes de dados de forma rápida e eficiente. Na maioria dos casos, você só precisa fornecer o endereço IP do host que deseja integrar.</span></p><p><span align="justify">Para plugins do tipo Template baseados em protocolos como ICMP ou SNMP, o provisionamento de fontes de dados é executado por meio da funcionalidade de Inventário (Inventory). (Consulte o capítulo Inventário para os procedimentos detalhados de provisionamento.)</span></p><p><span align="justify">Uma vez logado no Viewtimanager, você pode acessar a biblioteca de plugins no menu V.S. Data Broker, onde todos os templates disponíveis estão listados e prontos para serem implementados.</span></p><p></p><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/Ek378PG5JfxqrXvnrdf9.png"></figure><p>Esta biblioteca está em constante atualização, adicionando novos plugins para novos fabricantes.</p><div class="sd-callout" data-callout-type="info"><strong>Nos templates de plugins não é recomendado alterar, adicionar ou excluir campos nas etapas de extração, transformação, carregamento (load) e esquema (schema). Você pode causar o mau funcionamento nos plugins. A única edição recomendada neste tipo de plugin é adicionar novos campos usando o recurso de decorador (explicado mais adiante neste guia).</strong></div><p></p>
