# **<span align="center">Introduction</span>**

<br />

<span align="justify">The Viewtimanager module allows integration with Active Directory, enabling domain users to authenticate and access the Viewtinet platform with their existing credentials. This integration streamlines user management by centralizing authentication and role assignments. Within this manual, we will also explain the creation of roles that allow modifying the behavior of the graphical user interface. In the following chapters, we will detail the necessary steps to configure and establish this connection.</span>
