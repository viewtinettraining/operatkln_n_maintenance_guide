<h1><strong><span align="center">Integração LDAP</span></strong></h1><p></p><p>O Viewtinet pode se integrar a um diretório LDAP para permitir o provisionamento automático de usuários no primeiro login. Siga estes passos para configurar o LDAP:</p><ol><li><p><strong>Abra Admin → Auth</strong><br>Navegue até a área <strong>Admin</strong> no menu à esquerda, em seguida, clique na aba <strong>Auth</strong> na parte superior.<br></p></li><li><p><strong>Habilite a Integração LDAP</strong><br>Na seção <strong>Viewiauth Integrations</strong>, marque a caixa <strong>Active</strong> da linha <strong>ldap</strong>.<br></p></li><li><p><strong>Selecione a Função Padrão para Usuários LDAP</strong><br>No menu suspenso <strong>Default Role</strong> para a linha <strong>ldap</strong>, escolha a função que será atribuída a todos os novos usuários LDAP no primeiro login (ex: <code>My_Role_4_LDAP</code>).<br></p></li><li><p><strong>Adicione a Conexão do Servidor LDAP</strong><br>Role para baixo até a seção <strong>LDAP Servers</strong> e clique em <strong>+ ADD NEW LDAP SERVER</strong>.<br>Preencha os parâmetros de conexão:</p><ul><li><p><strong>Endereço IP</strong>: IP do servidor LDAP</p></li><li><p><strong>Porta</strong>: tipicamente <code>389</code></p></li><li><p><strong>Base DB</strong>: o DN base do seu diretório (ex: <code>dc=viewtinet,dc=local</code>)</p></li><li><p><strong>Admin Access DN</strong>: o bind DN do LDAP (ex: <code>cn=admin,dc=viewtinet,dc=local</code>)</p></li><li><p><strong>Senha do Admin</strong>: senha para o bind DN</p></li><li><p><strong>Campo de Usuário Único</strong>: atributo LDAP para pesquisa de nome de usuário (ex: <code>uid</code>)<br></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/MWyRnwIzFWY11JC8pkeJ.png" align="center"></figure><p></p></li></ul></li><li><p><strong>Salvar Configuração</strong><br>Clique em <strong>SAVE CHANGES</strong> na parte inferior para aplicar suas configurações de LDAP.</p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/xXRtwIZpZgPCrTY2XOKD.png" align="center"></figure><p><br></p></li></ol><hr><blockquote><p><strong>Nota:</strong> Os usuários LDAP serão provisionados automaticamente com a função padrão selecionada no primeiro login. Se um usuário LDAP precisar de uma função diferente, atribua-a manualmente via <strong>Admin → Users</strong> ou <strong>Admin → Groups</strong> após a conta ser criada.</p></blockquote><p></p>
