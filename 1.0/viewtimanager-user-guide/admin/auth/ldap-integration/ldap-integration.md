<h1><strong><span align="center">LDAP Integration</span></strong></h1><p></p><p>Viewtinet can integrate with an LDAP directory to allow auto-provisioning of users on first login. Follow these steps to configure LDAP:</p><ol><li><p><strong>Open Admin → Auth</strong><br>Navigate to the <strong>Admin</strong> area in the left menu, then click the <strong>Auth</strong> tab at the top.<br></p></li><li><p><strong>Enable LDAP Integration</strong><br>In the <strong>Viewiauth Integrations</strong> section, check the <strong>ldap</strong> row’s <strong>Active</strong> box.<br></p></li><li><p><strong>Select Default Role for LDAP Users</strong><br>In the <strong>Default Role</strong> dropdown for the <strong>ldap</strong> row, choose the role that will be assigned to all new LDAP users upon first login (e.g. <code>My_Role_4_LDAP</code>).<br></p></li><li><p><strong>Add LDAP Server Connection</strong><br>Scroll down to the <strong>LDAP Servers</strong> section and click <strong>+ ADD NEW LDAP SERVER</strong>.<br>Fill in the connection parameters:</p><ul><li><p><strong>IP Address</strong>: LDAP server IP</p></li><li><p><strong>Port</strong>: typically <code>389</code></p></li><li><p><strong>Base DB</strong>: your directory base DN (e.g. <code>dc=viewtinet,dc=local</code>)</p></li><li><p><strong>Admin Access DN</strong>: LDAP bind DN (e.g. <code>cn=admin,dc=viewtinet,dc=local</code>)</p></li><li><p><strong>Admin Password</strong>: password for the bind DN</p></li><li><p><strong>Unique User Field</strong>: LDAP attribute for username lookup (e.g. <code>uid</code>)<br></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/MWyRnwIzFWY11JC8pkeJ.png" align="center"></figure><p></p></li></ul></li><li><p><strong>Save Configuration</strong><br>Click <strong>SAVE CHANGES</strong> at the bottom to apply your LDAP settings.</p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/xXRtwIZpZgPCrTY2XOKD.png" align="center"></figure><p><br></p></li></ol><hr><blockquote><p><strong>Note:</strong> LDAP users will be auto-provisioned with the selected default role on first login. If an LDAP user requires a different role, assign it manually via <strong>Admin → Users</strong> or <strong>Admin → Groups</strong> after their account is created.</p></blockquote><p></p>
