<h1><strong><span align="center">Comandos</span></strong></h1><p><span align="justify">O painel de Comandos (Commands) do Network Configuration Manager é onde você pode visualizar, gerenciar e executar modelos de comando reutilizáveis em seus dispositivos de rede. Aqui você encontrará uma lista pesquisável de todos os comandos existentes, com opções para coletar configurações de dispositivos, exigir configurações pré-existentes ou excluir entradas. Use esta seção para executar rapidamente verificações operacionais, recuperar configurações em execução (running) ou de inicialização (startup) e enviar (push) alterações de configuração de maneira controlada e repetível.</span></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/fSO8MAg9r0KSIbXbOnF2.png" align="center"></figure><p><span align="justify">Você pode selecionar qualquer um dos comandos existentes na lista para executá-los imediatamente em um ou mais dispositivos. Se precisar criar um novo modelo de comando, clique em Adicionar um Novo Comando (Add a New Command) e siga os passos mostrados abaixo.</span></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/0tqX5JVHb7OpW8v329GL.png" align="center"></figure><p></p><p>Ao criar ou editar um comando, você deve fornecer:</p><ol><li><p><strong>Nome (Name)</strong> – Um rótulo descritivo para fácil identificação.</p></li><li><p><strong>Comando (Command)</strong> – O texto real a ser enviado (veja as opções de <strong>Tipo</strong> abaixo).</p></li><li><p><strong>Tipo (Type)</strong> – Escolha como o payload do comando é estruturado.</p></li><li><p><strong>Exigir Configuração (Require Config)</strong> – Se marcado, este comando só será executado em dispositivos com uma configuração existente.</p></li><li><p><strong>Coletar Configuração (Collect Config)</strong> – Se marcado, a configuração do dispositivo será buscada automaticamente após a execução.</p></li></ol><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/9UZ7GLSz3aXMc2ALHA3F.png"></figure><p><strong>Tipos de Comando (Command Types)</strong></p><ul><li><p><strong>Lista de Comandos (Commands List)</strong><br>Uma lista separada por ponto e vírgula de comandos operacionais pontuais (ex: <code>show version; show interfaces</code>). Use para consultas gerais, não de configuração.</p></li><li><p><strong>Conjunto de Configuração (Config Set)</strong><br>Uma lista separada por ponto e vírgula de comandos de configuração a serem aplicados em sequência (ex: <code>interface GigabitEthernet0/1; description Uplink</code>). <strong>Não</strong> inclua o comando para entrar no modo de configuração — apenas os próprios comandos.</p></li><li><p><strong>Arquivo de Configuração (Config File)</strong><br>Faça o upload de um arquivo contendo o conjunto completo de comandos de configuração. Isso é melhor para grandes modelos de configuração pré-construídos ou backups que você deseja enviar (push) por atacado.</p></li><li><p><strong>Lista de Prompts de Comandos (Commands Prompt List)</strong><br>Uma lista de pares <code>{comando ↔ prompt-esperado}</code> para sessões interativas avançadas. Use isso quando precisar conduzir diálogos complexos (por exemplo, navegar em assistentes de vários estágios ou lidar com prompts de dispositivos personalizados).</p></li></ul><p></p>
