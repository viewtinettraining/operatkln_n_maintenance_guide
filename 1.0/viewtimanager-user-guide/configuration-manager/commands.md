<h1><strong><span align="center">Commands</span></strong></h1><p><span align="justify">The Commands pane of the Network Configuration Manager is where you can view, manage, and execute reusable command templates against your network devices. Here you’ll find a searchable list of all existing commands, with options to collect device configurations, require pre‑existing configs, or delete entries. Use this section to quickly run operational checks, retrieve running or startup configurations, and push configuration changes in a controlled, repeatable way.</span></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/fSO8MAg9r0KSIbXbOnF2.png" align="center"></figure><p><span align="justify">You can select any of the existing commands in the list to run them immediately against one or more devices. If you need to create a brand‑new command template, click Add a New Command and follow the steps shown below.</span></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/0tqX5JVHb7OpW8v329GL.png" align="center"></figure><p></p><p>When creating or editing a command, you must supply:</p><ol><li><p><strong>Name</strong> – A descriptive label for easy identification.</p></li><li><p><strong>Command</strong> – The actual text to send (see <strong>Type</strong> options below).</p></li><li><p><strong>Type</strong> – Choose how the command payload is structured.</p></li><li><p><strong>Require Config</strong> – If checked, this command will only run against devices with an existing config.</p></li><li><p><strong>Collect Config</strong> – If checked, the device’s configuration will be automatically fetched after execution.</p></li></ol><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/9UZ7GLSz3aXMc2ALHA3F.png"></figure><p><strong>Command Types</strong></p><ul><li><p><strong>Commands List</strong><br>A semicolon‑separated list of one‑off operational commands (e.g. <code>show version; show interfaces</code>). Use for general, non‑configuration queries.</p></li><li><p><strong>Config Set</strong><br>A semicolon‑separated list of configuration commands to apply in sequence (e.g. <code>interface GigabitEthernet0/1; description Uplink</code>). Do <strong>not</strong> include the command to enter configuration mode—only the commands themselves.</p></li><li><p><strong>Config File</strong><br>Upload a file containing the full set of configuration commands. This is best for large, pre‑built configuration templates or backups that you wish to push wholesale.</p></li><li><p><strong>Commands Prompt List</strong><br>A list of <code>{command ↔ expected‑prompt}</code> pairs for advanced interactive sessions. Use this when you need to drive complex dialogues (for example, navigating multi‑stage wizards or handling custom device prompts).</p></li></ul><p></p>
