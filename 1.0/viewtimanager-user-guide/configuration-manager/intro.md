# **<span align="center">Introdução</span>**

<span align="justify">O Configuration Manager no Viewtinet é um recurso abrangente projetado para simplificar e automatizar o gerenciamento de configurações de dispositivos em toda a sua rede. Ele permite que os administradores apliquem, atualizem e mantenham configurações de forma eficiente em vários dispositivos simultaneamente, reduzindo o esforço manual e o risco de erro humano. Aproveitando os dados de inventário e credenciais de acesso seguro, o Configuration Manager garante que as tarefas de configuração sejam direcionadas de forma precisa e executadas de forma confiável. Este recurso suporta vários protocolos, como SSH e Telnet, para interagir com dispositivos remotamente, tornando-se uma ferramenta flexível e poderosa para administração de redes. Em geral, aumenta a eficiência operacional e a consistência no gerenciamento de configuração em diversos ambientes de rede.</span>
