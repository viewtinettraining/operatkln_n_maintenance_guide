# **<span align="center">Introdução</span>**

<br />

<span align="justify">O módulo Viewtimanager permite a integração com o Active Directory, possibilitando que os usuários do domínio se autentiquem e acessem a plataforma Viewtinet com suas credenciais existentes. Esta integração agiliza o gerenciamento de usuários centralizando a autenticação e as atribuições de funções. Dentro deste manual, também explicaremos a criação de funções que permitem modificar o comportamento da interface gráfica de usuário. Nos capítulos seguintes, detalharemos as etapas necessárias para configurar e estabelecer esta conexão.</span>
