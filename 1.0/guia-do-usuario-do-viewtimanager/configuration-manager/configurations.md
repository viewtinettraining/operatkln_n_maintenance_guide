<h1><strong><span align="center">Configurações</span></strong></h1><p></p><p><span align="justify">A aba de Configurações (Configurations) é o seu arquivo central para todas as saídas de dispositivos coletadas (normalmente backups de running-config ou startup-config). Você pode navegar em diretórios, visualizar arquivos brutos, baixar ou comparar snapshots e — quando pronto — mesclar (merge) várias capturas em um único arquivo consolidado.</span></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/IzrHdGro2M4apBy4Z9Y2.png" align="center"></figure><p></p><ol><li><p><strong>Navegue no seu arquivo</strong><br>Clique em <strong>Navegador de Arquivos (File Browser)</strong> para abrir uma exibição hierárquica de todas as pastas e arquivos de configuração. Aprofunde-se nos nomes das tarefas (tasks), subtarefas ou diretórios específicos do dispositivo para localizar arquivos <code>.cfg</code> individuais.</p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/TahQXv63UxaXQI3ntgCP.png" align="center"></figure><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/deAkevp0gL45LzMB3GLs.png" align="center"></figure><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/GQChaXKTGLxwNS9iSfZz.png" align="center"></figure><p></p></li><li><p><strong>Pesquisar, Editar ou Excluir</strong><br>De volta à lista principal, use o ícone de <strong>Pesquisa (Search)</strong> (🔍) para visualizar um arquivo inline, <strong>Editar (Edit)</strong> (✏️) para renomeá-lo, ou <strong>Excluir (Delete)</strong> (🗑️) para removê-lo do arquivo.</p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/0gQTeC41DROskFX1Ddzh.png" align="center"></figure><p></p></li><li><p><strong>Baixar Arquivos Selecionados</strong><br>Selecione uma ou mais configurações nas caixas de seleção, então clique em <strong>Download Selected</strong> para agrupá-las em um ZIP para armazenamento offline ou auditoria.</p><p></p></li><li><p><strong>Comparar Dois Snapshots</strong><br>Para identificar diferenças entre duas capturas, selecione exatamente dois arquivos e clique em <strong>Compare Selected</strong>. Um visualizador de diff lado a lado destacará as linhas adicionadas, removidas ou alteradas.</p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/aRr32fgoZpQVAE1LuBXL.png" align="center"></figure><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/Fi72EjNsSiPv4LLpe41s.png" align="center"></figure><p></p></li><li><p><strong>Mesclar Várias Capturas</strong><br>Selecione dois (ou mais) snapshots e clique em <strong>Merge Selected</strong> para abrir o editor de mesclagem. Você verá cada arquivo lado a lado; depois de resolver quaisquer conflitos, você pode clicar em <strong>Merge</strong> para criar um arquivo <code>.cfg</code> unificado.</p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/36kPUwkbW21h8XhFss15.png" align="center"></figure><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/o16HcrWNNphk1dYg/images/YueuLTTPLzfhe8eX4MsJ.png" align="center"></figure><p></p></li></ol><p><strong>Dica:</strong> Use <strong>Compare</strong> antes do <strong>Merge</strong> para garantir que você entenda cada mudança. Os arquivos mesclados aparecerão no arquivo com um nome com carimbo de data/hora para rastreabilidade.</p><p></p>
