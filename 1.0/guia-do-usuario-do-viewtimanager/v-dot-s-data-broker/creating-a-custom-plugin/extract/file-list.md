<h1><strong><span align="center">Conector File List</span></strong></h1><p></p><p>O <strong>Conector File List</strong> é um conector agendado projetado para ler arquivos de um diretório específico no servidor Viewtilog e movê-los para outro local para processamento posterior. Este conector é especialmente útil ao trabalhar com sistemas externos que depositam arquivos (ex., logs CSV, relatórios ou registros detalhados de chamadas).</p><p>Assim que os arquivos são movidos para o diretório de saída designado, eles podem ser enviados posteriormente para um dispositivo externo no <strong>estágio Load</strong> usando o <strong>Produtor SCP</strong> (explicado em detalhes em uma seção posterior).</p><p>Ao contrário de conectores contínuos, como o <strong>Ethernet Streamer</strong>, o Conector File List opera num <strong>modelo de execução agendada</strong>: ele é executado em intervalos definidos ou de acordo com uma expressão cron, dependendo do <strong>Tipo de Frequência</strong> selecionado.</p><p></p><h2><strong>Principais Recursos</strong></h2><ul><li><p>Lê arquivos de um diretório <em>to-collect</em> (para coletar) configurável.</p></li><li><p>Move arquivos para um diretório <em>to-send</em> (para enviar) para processamento posterior.</p></li><li><p>Suporta <strong>Execução periódica</strong> (a cada X segundos) ou <strong>Execução agendada</strong> (expressão cron).</p></li><li><p>Permite definir o <strong>número máximo de arquivos</strong> para processar por execução.</p></li><li><p>O sufixo do arquivo pode ser especificado (ex., <code>.csv</code>).</p></li><li><p>Funciona perfeitamente com o <strong>Produtor SCP</strong> para entregar arquivos a destinos remotos.</p></li></ul><p></p><h2><strong>Configuração Passo a Passo</strong></h2><p>Siga estas etapas para configurar o <strong>Conector File List</strong>:</p><ol><li><p><strong>Selecione o Tipo de Conector</strong></p><ul><li><p>Na janela <em>Editando o Estágio Extract</em>, escolha <strong>Conector File List</strong> na lista suspensa.</p></li></ul></li><li><p><strong>Atribua um Nome ao Pipeline</strong></p><ul><li><p>Insira um <strong>nome exclusivo de pipeline</strong>.</p></li><li><p>Exemplo: <code>meu_conector_file_list</code>.</p></li></ul></li><li><p><strong>Configure o Tempo de Execução</strong></p><ul><li><p>Escolha o <strong>Tipo de Frequência</strong>:</p><ul><li><p><strong>Periódico</strong> → Executa a cada X segundos (configurado no <em>Tempo de Atualização</em>).</p></li><li><p><strong>Agendado</strong> → Executa de acordo com uma expressão cron.</p></li></ul></li><li><p>Exemplo: Periódico com tempo de atualização = <code>60</code> segundos.</p></li></ul></li><li><p><strong>Defina os Caminhos</strong></p><ul><li><p><strong>Caminho para coletar (To-collect)</strong>: O diretório onde os arquivos são armazenados inicialmente.</p></li><li><p><strong>Caminho para enviar (To-send)</strong>: O diretório para onde os arquivos serão movidos após serem coletados.</p></li></ul></li><li><p><strong>Defina as Propriedades do Arquivo</strong></p><ul><li><p><strong>Sufixo</strong>: Define o formato de arquivo esperado (ex., <code>.csv</code>).</p></li><li><p><strong>Máx de Arquivos</strong>: Número máximo de arquivos a serem processados durante uma execução.</p></li></ul></li><li><p><strong>Confirme a Configuração</strong></p><ul><li><p>Quando todos os parâmetros estiverem definidos, clique em <strong>Confirmar</strong> para salvar e ativar o conector.</p><p></p></li></ul></li></ol><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/JQKTY4r9i7A0faASpOYL.png" align="center"></figure><p></p><h3><strong>Exemplo de Configuração (baseado na imagem)</strong></h3><ul><li><p><strong>Tipo de Conector</strong>: Conector File List</p></li><li><p><strong>Nome do Pipeline</strong>: <code>meu_conector_file_list</code></p></li><li><p><strong>Tipo de Frequência</strong>: Periódico</p></li><li><p><strong>Tempo de Atualização</strong>: 60 segundos</p></li><li><p><strong>Número de Execuções</strong>: <code>-1</code> (executa indefinidamente)</p></li><li><p><strong>Caminho To-collect</strong>: <code>/opt/vn/dhyana/var/data/%%%PLUGIN_NAME%%%/to_collect/</code></p></li><li><p><strong>Caminho To-send</strong>: <code>/opt/vn/dhyana/var/data/%%%PLUGIN_NAME%%%/to_send/</code></p></li><li><p><strong>Sufixo</strong>: <code>.csv</code></p></li><li><p><strong>Máx de Arquivos</strong>: 50</p><p></p></li></ul><h2><strong>Resumo</strong></h2><p>O Conector File List é ideal para cenários em que sistemas externos depositam arquivos num local compartilhado para coleta. Ao mover arquivos entre diretórios, ele garante um processamento ordenado e prepara os dados para entrega segura usando Produtores como o <strong>SCP</strong>.</p>
