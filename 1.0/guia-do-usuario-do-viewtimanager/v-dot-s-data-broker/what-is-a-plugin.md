<h1><strong><span align="center">O que é um Plugin?</span></strong></h1><p><span align="justify">Um plugin é um conceito introduzido pela Viewtinet para integrar as fontes de dados de maneira fácil utilizando a interface gráfica (GUI). Um plugin contém as etapas de ETL para obter as informações das fontes de dados usando diferentes protocolos (SNMP, ICMP, Netflow, CSV, XDR). Ele abrange a transformação dos dados e o carregamento para o banco de dados. Após isso ser feito, você pode usar ferramentas como o Metrics Composer (Veja o Guia do Usuário do Viewtisight) para criar métricas a partir dos dados carregados.</span></p><p></p><figure><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/p5zE6ydAjaAmMLFipxVp.png" align="middle"></figure><p>Um plugin consiste em:</p><ul><li><p><strong>Pipeline:</strong> o conjunto de etapas (stages) que permite obter os dados, transformá-los e carregá-los num banco de dados de séries temporais. Abaixo há uma explicação para cada etapa:</p><ul><li><p><strong>Extract (Extrair):</strong> Etapa usada para conectar com uma fonte de dados e extrair seus dados. Nesta etapa, são definidos os campos a serem obtidos de acordo com o protocolo usado. Por exemplo, OIDs SNMP, campos de Syslog, NetFlow, ou arquivo csv, e o IP para essas fontes de dados.</p></li><li><p><strong>Transform (Transformar):</strong> Os dados obtidos na etapa anterior podem ser transformados em novos campos usando operações matemáticas (para campos numéricos). Também é possível transformar os dados adicionando informações usando o recurso CSV Decorator. Outras possibilidades são Column Remover (Removedor de Coluna), Column Constant Adder (Adicionador de Constante de Coluna), Date Converter (Conversor de Data), Regex e Key-Value (Chave-Valor), entre outras.</p></li><li><p><strong>Load (Carregar):</strong> os dados obtidos e transformados podem ser despejados em um arquivo CSV ou carregados em bancos de dados de séries temporais. Pode até executar ambas as ações ao mesmo tempo. Também são definidos a tabela, os nomes dos campos e os seus tipos (Varchar, Numeric, BIGINT)</p></li><li><p><strong>Schema (Esquema):</strong> nesta etapa, os dados são preparados para serem usados no Módulo Viewtisight. É aqui que as métricas e as dimensões são definidas.</p></li><li><p><strong>Dashboards:</strong> esta etapa é opcional. Um plugin pode ter dashboards predefinidos para fontes de dados específicas.</p></li></ul></li><li><p><strong>Name (Nome):</strong> Nome descritivo do plugin, ex. "Fortinet's Network Monitoring Template".</p></li><li><p><strong>Category (Categoria):</strong> Cada plugin pertence a uma categoria, ex. SNMP, Networking, SSH, Syslog, entre outras.</p></li><li><p><strong>Dependencies (Dependências):</strong> mostra os módulos que são obrigatórios para a instalação do plugin.</p></li><li><p><strong>Description (Descrição):</strong> Uma descrição do plugin, ex: "Viewtinet Template for Fortinet Firewalls: status, health and interface monitoring (includes dashboards)".</p></li><li><p><strong>Image (Imagem):</strong> Uma imagem em formato jpg/png para identificar o plugin.</p></li></ul><p></p><p>As capturas de tela seguintes mostram todos os campos do plugin:</p><p></p><p></p><figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/nnoeT0qAXnL7T0qi/images/nKjjFtOOWRrWf1YMpjgy.png" align="middle"></figure><p></p>
