# **<span align="center">Ativação do Usuário Admin</span>**

<span align="justify">Após a conclusão do processo de instalação, é necessário ativar o usuário admin. Para isso, use o navegador de sua preferência para acessar a página http://x.x.x.x:4200, onde x.x.x.x é o endereço do appliance, máquina virtual ou servidor COTS onde você concluiu a instalação.</span>

<span align="justify">Você será apresentado à tela de login onde deve usar as credenciais padrão: nome de usuário: admin, senha: Viewtinet01!</span>

<figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/DbeVQqyuMpxgxMbG/images/4ALTdYAA8VEKZEUYl5jr.png" align="center"></figure>

<span align="justify">Você será solicitado a criar uma senha para o usuário admin. Você deve inserir a senha desejada e rememberá-la, pois será a senha que você usará para a conta admin a partir de agora.</span>

<figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/DbeVQqyuMpxgxMbG/images/QY4FBQcq7xD0kTnKF4QY.png" align="center"></figure>
