# **<span align="center">Admin User Activation</span>**

<span align="justify">Once the installation process is complete, it is necessary to activate the admin user. To do this,Please use your preferred browser to visit the page http://x.x.x.x:4200, where x.x.x.x is the address of the appliance, virtual machine, or COTS server where you have completed the installation.</span>

<span align="justify">You will be presented with the login screen where you should use the default credentials: username: admin, password: Viewtinet01!</span>

<figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/DbeVQqyuMpxgxMbG/images/4ALTdYAA8VEKZEUYl5jr.png" align="center"></figure>

<span align="justify">You will be prompted to create a password for the admin user. You should enter your desired password and remember it, as it will be the password you use for the admin account from now.</span>
