# <span align="center">Installation Step 3</span>

<br />

<div class="sd-callout" data-callout-type="info">In this step, the container images will be loaded, and configuration related to internal networking, port forwarding, and other tasks will be performed</div>

To execute this step, you need to reconnect to the server via SSH, just as it was done in the "SSH Connection" section.

<br />

Once logged back into the system, you should re-execute the command as shown below

```bash
/opt/vn/viewtinet-builder/install.sh
```
