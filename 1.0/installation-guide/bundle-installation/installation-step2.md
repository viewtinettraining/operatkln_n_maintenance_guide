# <span align="center">Passo 2 da Instalação</span>

<div class="sd-callout" data-callout-type="info">Nesta etapa, todas as dependências serão instaladas. Ao final do processo, você precisará se desconectar da sessão SSH e fazer login novamente para prosseguir com a próxima etapa.</div>

Para iniciar o processo de instalação, você deve executar o seguinte comando.

```bash
/opt/vn/viewtinet-builder/install.sh
```

<br />

Ao final do processo, você receberá uma mensagem indicando que a etapa foi concluída e que é necessário fechar a sua sessão SSH atual e fazer login novamente.

<br />

<figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/DbeVQqyuMpxgxMbG/images/Zkhpqv7oEiD4n22t6Z4R.png" align="center"></figure>

Neste ponto, você deve se desconectar completamente do servidor. Dependendo da sua ferramenta SSH:
- Se estiver usando um terminal padrão, digite `exit` e pressione Enter, ou simplesmente feche a janela do terminal.
- Se estiver usando um cliente com interface gráfica (ex: PuTTY, MobaXterm), feche o aplicativo clicando no ícone "X" ou encerrando a sessão explicitamente.

Assim que a sessão for totalmente fechada, inicie uma nova conexão SSH para prosseguir com as próximas etapas.
