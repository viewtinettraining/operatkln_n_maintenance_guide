# **<span align="center">About</span>**

<br />

<span align="justify">Viewtisight is the powerful analytics and business intelligence layer of the Viewtinet platform, designed to turn the high-volume data ingested by the Viewtilog module into actionable, visually engaging insights.</span>

<span align="justify">It features tools such as the Dashboard Composer for building interactive dashboards, the Metrics Composer for defining custom KPIs, the PDF Reporter for automated report generation, and a Control Center for managing alarms and notifications. With both real-time and historical view leveraging years of archived data and a rich set of preconfigured yet fully customizable dashboards with drill-down capabilities, Viewtisight empowers you to monitor network performance, detect anomalies, and act on critical events through advanced alarms based on thresholds or anomaly detection.</span>
