# **<span align="center">Sobre</span>**

<br />

<span align="justify">O Viewtisight é a poderosa camada de análise e inteligência de negócios da plataforma Viewtinet, projetada para transformar o alto volume de dados ingeridos pelo módulo Viewtilog em insights acionáveis e visualmente envolventes.</span>

<span align="justify">Ele apresenta ferramentas como o Dashboard Composer para construir painéis interativos, o Metrics Composer para definir KPIs personalizados, o PDF Reporter para geração automatizada de relatórios e um Control Center para gerenciar alarmes e notificações. Com uma visão tanto em tempo real quanto histórica aproveitando anos de dados arquivados e um conjunto rico de painéis pré-configurados e totalmente personalizáveis com recursos de drill-down (detalhamento), o Viewtisight permite monitorar o desempenho da rede, detectar anomalias e agir em eventos críticos por meio de alarmes avançados baseados em limites ou detecção de anomalias.</span>
