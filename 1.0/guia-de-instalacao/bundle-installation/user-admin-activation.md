# **<span align="center">Ativação do Usuário Administrador</span>**

<span align="justify">Assim que o processo de instalação for concluído, é necessário ativar o usuário administrador. Para isso, use o seu navegador preferido para visitar a página http://x.x.x.x:4200, onde x.x.x.x é o endereço do appliance, máquina virtual ou servidor COTS no qual você concluiu a instalação.</span>

<span align="justify">Você verá a tela de login onde deverá usar as credenciais padrão: nome de usuário: admin, senha: Viewtinet01!</span>

<figure align="center"><img src="https://app.snazzydocs.com/storage/users/ucsRFoMgaUeUU6iR/docs/DbeVQqyuMpxgxMbG/images/4ALTdYAA8VEKZEUYl5jr.png" align="center"></figure>

<span align="justify">Você será solicitado a criar uma senha para o usuário administrador. Você deve inserir a senha desejada e memorizá-la, pois ela será a senha que você usará para a conta de administrador a partir de agora.</span>
