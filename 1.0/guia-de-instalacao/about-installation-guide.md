# **<span align="center">Introdução</span>**

> ## **Aviso Legal e Notas Importantes:**
> 
> -   O Viewtinet é compatível **apenas** com as versões **20.04** ou **24.04** do Ubuntu Server. A instalação ou execução em outras versões de sistema operacional ou distribuições diferentes **não é suportada**.
> -   Este manual **não** cobre procedimentos para:
>     
>     -   Criação de mídia de instalação ou inicialização para o sistema operacional Ubuntu Server.
>     -   Conexão ao servidor físico ou configuração de acesso remoto para a instalação do sistema operacional.
>     -   Implantação do Ubuntu Server em máquinas virtuais ou ambientes em nuvem.
>     -   Processos de particionamento de disco.
> -   No entanto, esta documentação fornece um esquema de particionamento recomendado (detalhado no Capítulo 2: Instalação) como uma diretriz.
> -   Todos os procedimentos e instruções neste manual começam **após** a instalação e particionamento do sistema operacional de acordo com as diretrizes fornecidas.
>     
>     <br />
>

## **Público-Alvo**

Este manual destina-se a administradores de TI, engenheiros DevOps e pessoal técnico com experiência em:

-   Administração de servidores baseados em Linux (especificamente Ubuntu Server).
-   Práticas de observabilidade e monitoramento.
-   Docker e ambientes em contêineres.

Espera-se que os usuários tenham proficiência suficiente em operações de linha de comando e tarefas de configuração do sistema.
