# **<span align="center">Directory Structure Overview</span>**

The Viewtinet platform is installed under the `/opt/vn/` directory, which serves as the central location for all configuration files, services, scripts, and runtime components. This structured layout enables system administrators and operators to easily locate and manage the resources associated with each module in the platform.

Understanding the purpose of each directory is essential when working from the CLI, especially for tasks such as:

-   Executing or reviewing maintenance scripts
-   Inspecting module-specific settings or logs
-   Managing updates and deployments

The directory structure is consistent across deployments and applies to all Viewtinet product lines, including **Viewtilog**, **Viewtimon**, and **Viewtify QoS**.

In the sections below, each directory will be explained in detail, including its role in the system and relevant operational considerations.
